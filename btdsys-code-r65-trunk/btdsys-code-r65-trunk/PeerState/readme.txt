BTDSYS PEERSTATE BETA 1

PeerState takes snapshots of the parameter states of several machines at once
(a bit like presets, but it's separate from Buzz's preset system - that's why
I'm calling them snapshots and not presets). You can keep upto 128 snapshots,
and restore them either in patterns or via the GUI. It's mainly useful for
live performances I guess.

This machine is in BETA stage, so it is not recommended that you use it in any
songs you want to keep or distribute.

INSTALLATION
Unzip it into gear\generators.

USAGE
* Right-click PeerState and select "Machines..."
* Highlight one or more machines and click OK.
* Double-click PeerState.
* Choose a snapshot number, click the big button marked "Take Snapshot".
* If you want, give the snapshot a name by typing into the "Name" box.
* Change parameters on the other machines and repeat the previous 2 steps.
* To restore them, select them from the list or sequence the "Snapshot"
  parameter.
* Snapshots are also saved along with the bm* file.
* Set MIDI up via the attributes. Notes will select the snapshot with the
  corresponding number, eg 'middle C' on most keyboards will select snapshot
  number 60, the G above that will select number 67, etc.
* You can optionally choose a MIDI note to act as a "take snapshot" key. Then
  pressing that key will act exactly like the big button marked "Take
  Snapshot" in the GUI.
