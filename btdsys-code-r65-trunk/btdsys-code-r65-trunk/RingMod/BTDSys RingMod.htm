BTDSys RingMod

Installation

Put BTDSys RingMod.dll in your Gear\Effects folder.

Overview

RingMod is a ring modulator effect, ie it multiplies together its input signals. Unlike other Buzz ring modulators, which either use auxbus or internal oscillators for one of the signals, RingMod multiplies any number of inputs connected directly to it.

  • Add RingMod to your song.
  • Connect at least 2 machines to RingMod, and RingMod to the Master.
  • Ensure that all connected machines are producing sound, otherwise RingMod will be silent.

This machine is really simple, and I'm tired, so that's all the docs you're getting :)
