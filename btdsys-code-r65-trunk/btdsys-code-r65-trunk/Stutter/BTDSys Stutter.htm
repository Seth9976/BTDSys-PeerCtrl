BTDSys Stutter

Installation

Put BTDSys Stutter.dll in your Gear\Generators folder.

Notes

  • There is an attribute ("Mode") to set whether the End/Length parameter sets the absolute end point, or the loop length (relative to the start point).
  • New to v1.1: Another attribute ("Time Rel To") sets whether Loop Time stretches the selected loop, or the whole wave to the specified length. So if this is set to 1, the playback rate of the loop stays constant even if you change the loop points.
  • If the end point is before the start point (or length is negative), the loop plays in the opposite direction to "normal".
  • Inertia A applies to Start and End/Length, Inertia B applies to Loop Time, Rate and Volume.
  • Only one of Loop Time or Rate is used at once (the one chosen by the Rate Par parameter). The other is just ignored.
